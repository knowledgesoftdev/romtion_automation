AUFIORA FORMULA — follow this exact structure:

1. HOOK (0:00–0:40 | ~100 words)
- Open with a contrast: something the viewer knows vs something they don't
- Short sentences. Each one lands like a punch.
- End the hook with: "Today, we're going through all of them."
- Never start with "In this video" or "Today I want to talk about"

2. CONTEXT BLOCK (0:40–2:00 | ~200 words)
- Explain the system or mechanism behind the topic
- Use real terminology (SAPs, Waived SAPs, NCA, compartmented access, etc.)
- Include one real verifiable reference (congressional testimony, declassified doc, named report)
- End with a line that raises the stakes: "And once you understand this, you'll never look at X the same way again."

3. MAIN LIST — each unit/item follows this exact pattern (~250 words each):
   a. Name + code name if applicable
   b. Origin story — when was it created and WHY (what failure or gap created the need)
   c. Unique mission — what makes it different from everything else
   d. The unexpected fact — the one detail that surprises even people who follow this topic
   e. Current status — is it still active? any recent confirmation?
   
   Include 6 to 7 units/items to hit the 2,300 word target.

4. THE CLIFFHANGER UNIT (12:00–15:00 | ~300 words)
- This is always the LAST unit in the list
- It must be the one with the LEAST official confirmation
- Build tension: "Everything we've covered has been confirmed at some point. This one hasn't."
- Reference one real but obscure document (court filing, executive order, anonymous official)
- Never fully resolve it — leave the viewer with more questions than answers
- End with: "And if you've never heard of it — that's exactly how they want it."

5. CLOSING + DEBATE QUESTION (15:00–17:00 | ~150 words)
- Bring all units back into the present tense — they are active NOW, not history
- Connect to something verifiable from the current year (renewed executive order, recent testimony, etc.)
- Final line is always a debate question for the comments
- Format: "Which do you think is more dangerous — [option A] or [option B]?"

- Never use filler phrases: "It's worth noting", "Interestingly", "As we can see"
- Never start consecutive sentences with the same word
- Use em dashes — like this — for dramatic pauses, not commas
- Numbers under ten are written as words. Numbers above ten use numerals.
- Every unit must have at least one real verifiable reference (named operation, document, year, named official or publication)
- Vary sentence length intentionally: short sentence after a long one creates rhythm
- The tone is: calm, authoritative, slightly ominous. Like a documentary narrator who knows more than they're saying.
